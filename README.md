# kho-anh

Kho lưu hình ảnh và nhạc dùng chung cho các dự án. Mỗi dự án một thư mục riêng.

| Thư mục | Dự án |
|---|---|
| `chanh-dien/` | Chánh Điện Online (hình nền, nhân vật, hiệu ứng, nhạc trong `music/`) |

## Link dùng trong các dự án khác

Dạng link (qua jsDelivr, nhanh và cho phép nhúng):

    https://cdn.jsdelivr.net/gh/HuynhCoKho/kho-anh@main/<thư-mục-dự-án>/<tên-file>

Ví dụ: `https://cdn.jsdelivr.net/gh/HuynhCoKho/kho-anh@main/chanh-dien/hall.jpg`

## Quy tắc để link không bị hỏng

- Không đổi tên file hoặc thư mục đã dùng. Muốn đổi hình, tải file mới lên với đúng tên cũ.
- Tên file viết thường, không dấu, không khoảng trắng (dùng dấu gạch ngang hoặc gạch dưới).
- Giữ repo ở chế độ Public.
